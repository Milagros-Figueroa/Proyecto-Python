# Proyecto-Python

- Este repositorio contiene el proyecto trabajado del curso Introducción a Python, desarrollado a través de BA Emprende.

El objetivo del proyecto es aplicar los principales conceptos aprendidos durante el curso, poniendo en práctica la programación con Python y la resolución de problemas mediante código.

## Contenidos trabajados

Durante el desarrollo del proyecto se aplican conceptos fundamentales de Python, entre ellos:

Variables y tipos de datos.
Operadores.
Condicionales (if, elif, else).
Bucles for y while.
Uso de range().
Listas y recorrido de elementos.
Funciones.
Entrada y salida de datos.
Uso de continue y otras estructuras de control.
Objetivo

El proyecto busca integrar los conocimientos adquiridos durante el curso mediante la creación de un programa funcional, poniendo énfasis en la lógica de programación y en la resolución de situaciones mediante Python.

Tecnologías utilizadas
Python 3
Visual Studio Code
Git / GitHub
